En este trabajo resolví el problema de la intersección de un solo carril, donde varios autos llegan desde cuatro direcciones distintas, pero únicamente uno puede cruzar a la vez. La idea principal es evitar que dos hilos entren simultáneamente a la zona crítica (la intersección), simulando así el control del tráfico de manera segura. El programa está desarrollado en Python 3 y se puede ejecutar prácticamente en cualquier entorno; no requiere librerías externas ni configuraciones especiales. Para correrlo basta con tener instalado Python 3, guardar el archivo como interseccion.py y ejecutarlo desde la terminal con el comando python3 interseccion.py. El comportamiento es continuo y el programa solo termina cuando el usuario lo detiene manualmente con Ctrl+C.

Para resolver la sincronización utilicé un semáforo binario, que actúa como un mecanismo de exclusión mutua sobre la intersección. Cada auto, antes de cruzar, solicita el semáforo; si la intersección está disponible, entra, y si ya hay un vehículo dentro, el hilo se bloquea automáticamente hasta que el recurso sea liberado. Al salir, el auto libera el semáforo para permitir el paso del siguiente. Esta estrategia es simple, directa y completamente acorde al nivel de sincronización que hemos visto en clase. Como refinamientos menores añadí variaciones aleatorias en el tiempo de llegada y en el tiempo que tarda cada auto en cruzar, con el objetivo de que la simulación no se vea artificial ni repetitiva.

Aunque el programa cumple con lo esencial del problema, reconozco que podrían incorporarse mejoras si se quisiera avanzar más: por ejemplo, manejar colas por dirección, implementar algún criterio de prioridad o fairness, o agregar controles para detener la simulación desde el mismo programa. Aun así, la solución presentada funciona correctamente, es fiel al planteamiento original y está implementada con las mismas herramientas y técnicas que usamos en clase, sin agregar mecanismos que no hayamos visto.
